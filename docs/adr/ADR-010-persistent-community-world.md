# ADR-010: Persistent community world

**Status:** Accepted

**Context:** The core product differentiator is community continuity across streams, not disposable chat minigames.

**Decision:** Model guilds, players, achievements, relationships, artifacts and chapter history as durable world records.

**Alternatives:** Session-only state (simpler but loses return value); shared global world across creators (breaks creator ownership and community identity).

**Consequences:** Each creator community has a stable world identity and auditable history; AI memory summaries are derived, replaceable views of that history.
